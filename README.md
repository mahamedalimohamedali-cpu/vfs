# Calculator

## Overview
This is a lightweight Windows desktop application designed to perform essential arithmetic calculations through a graphical user interface. It utilizes a custom string-parsing engine to evaluate mathematical expressions entered by the user.

## Key Features
*   **Multi-Operand Arithmetic**: Supports a variety of operations including addition, subtraction, multiplication, floating-point division, and modulo.
*   **Expression Evaluation**: Features a logic-driven calculation engine that parses input strings to process sequential operations.
*   **Input Management**: Includes built-in functionality for character-by-character correction (backspace), full workspace clearing, and standard numeric input.

## Technical Stack
*   **Language**: C#
*   **Framework**: .NET Framework 3.5
*   **UI Library**: Windows Forms (WinForms)
